# HU-92.3 — Confirmaciones transaccionales de Auction

El endpoint interno firmado de confirmaciones de Auction admite tres contratos
nuevos, todos `eventVersion: 1` y `producer: "auction"`:

| Evento                                     | Avisos in-app persistidos                                                                                                   |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `auction.buy-now.completed`                | Acreditación al vendedor (incluye `transferId`) y compra completada al comprador (incluye `transactionId`).                 |
| `auction.product.claimed`                  | Producto recibido al ganador.                                                                                               |
| `auction.settled` con `captureOperationId` | Acreditación al vendedor con la referencia de captura Wallet; se conservan los avisos existentes para ganador y perdedores. |

Cada aviso usa un ID determinista derivado de `eventId` y del rol. Los replays
devuelven duplicados sin crear un segundo aviso. Los contratos rechazados no
persisten notificaciones y la ausencia de entrega no cambia el resultado de
Auction.
