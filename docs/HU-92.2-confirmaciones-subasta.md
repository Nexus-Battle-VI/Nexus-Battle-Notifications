# HU-92.2 — Confirmaciones de publicación y puja

Notifications recibe `POST /api/internal/v1/notifications/auction/confirmations`
firmado por Auction con HMAC. Acepta exclusivamente los contratos v1:

- `auction.published`: crea `AUCTION_PUBLISHED` para el vendedor.
- `auction.bid.accepted`: crea `AUCTION_NEW_BID` para el vendedor y
  `AUCTION_BID_ACCEPTED` para el postor.

Cada aviso recibe un identificador determinista derivado de `eventId` y rol.
Un replay valida el contenido previamente persistido y no crea otro aviso. Un
contrato inválido o una firma inválida se rechaza antes de persistir.
